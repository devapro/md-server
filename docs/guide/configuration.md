# Configuration

| Variable        | Default  | Description                         |
| --------------- | -------- | ----------------------------------- |
| `DOCS_DIR`      | `./docs` | Host folder with Markdown files     |
| `HOST_PORT`     | `8080`   | Host port                           |
| `SITE_TITLE`    | `Docs`   | Name in the top bar                 |
| `MD_ALLOW_HTML` | `false`  | Render raw HTML inside Markdown     |

> **Tip:** links between documents are plain relative links, e.g. `[API](../reference/api.md)`.
